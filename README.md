# 👋 Hi, We're RUNTIME Robotics!

**Powering Physical AI Robots — From Simulation to Deployment.**

We are [RUNTIME Robotics](https://runtimerobotics.com/), a robotics software engineering company based in Kochi, Kerala, India.

We specialize in building intelligent robotic systems using **ROS 2, NVIDIA Omniverse, Isaac Sim, Physical AI, and advanced robot learning technologies**.

### 👀 What We're Working On

- 🤖 **Physical AI & Embodied Intelligence** — Intelligent robots that perceive, reason, learn, and interact with the physical world.
- 🦾 **Humanoid & Quadruped Robotics** — Navigation, manipulation, locomotion, perception, and autonomous applications.
- 🚀 **ROS 2 Development** — Robot navigation, manipulation, perception, hardware integration, and autonomous control.
- 🌐 **NVIDIA Omniverse & Isaac Sim** — Robot simulation, digital twins, synthetic data generation, and sim-to-real workflows.
- 🧠 **Robot Learning** — Reinforcement learning, imitation learning, and Vision-Language-Action (VLA) models.
- 🏭 **Industrial Robotics & AMRs** — Autonomous mobile robots, motion planning, inspection, and industrial automation.
- 🎓 **Robotics Education & Training** — Practical training in ROS 2, NVIDIA Isaac, simulation, and Physical AI.
